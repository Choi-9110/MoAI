# moai 제품 플로우

> 확정일: 2026-08-20
> 캘린더에서 공고를 발견하고 → 사업계획서를 만들고 → 한 장으로 보며 고쳐나가는 흐름

---

## 전체 흐름

```
① 캘린더 자동 분석      매일 Gemma 가 신규 공고 지원여부 판정        [구현 완료]
        ↓
② 지원하기              공고문 첨부 + 사업계획서 작성/불러오기
                        → 로컬 Claude 1차 분석
        ↓
③ 이미지화              구조화된 인포그래픽 1장으로 렌더링
        ↓
④ 부분 수정             블록 클릭 → 텍스트 편집 → 재생성
        ↓
      ③④ 반복
        ↓
⑤ 최신화                "지금까지 내용을 아이디어에 반영할까요?"
        ↓
⑥ 재작성                갱신된 아이디어로 사업계획서 다시 작성 (수동 버튼)
```

**①은 자동, ②~⑥은 사용자가 주도한다.** 자동화는 "발견"까지만이고,
작성은 사람이 보면서 고쳐야 품질이 나온다.

---

## ③ 이미지화 — 이게 핵심 차별점

### 무엇인가

사업계획서 텍스트를 **A4 한 장짜리 인포그래픽**으로 렌더링한다.
글로만 된 사업계획서는 구조가 안 보이는데, 한 장으로 보면 빈 곳이 드러난다.

### 레이아웃 구조 (레퍼런스 분석)

```
┌────────────────────────────────────────┐
│  제목 배너                    다크 네이비 │
├────────────────────────────────────────┤
│  [주관] 로고+역할   [참여] 로고+역할     │  카드 그리드 2×2
│  [참여] 로고+역할   [공동] 로고+역할     │  배지로 역할 구분
├────────────────────────────────────────┤
│  보조 설명 바 (아이콘 + 한 줄)            │
├──────┬─────────────────────────────────┤
│ 사업 │ 본문 2~3줄                        │  라벨 + 본문
│ 목표 │                          네이비   │
├──────┼─────────────────────────────────┤
│ 내부 │ ①카드  ②카드  ③카드              │  라벨 + 3열 카드
│문제점│                          빨강     │  번호 배지 + ⚠ 아이콘
├──────┼─────────────────────────────────┤
│ 해결 │ ①카드  ②카드  ③카드              │  라벨 + 3열 카드
│ 방안 │                          파랑     │  번호 배지 + 일러스트
├──────┼─────────────────────────────────┤
│ 외부 │ 문제 카드  │  해결 카드           │  2열 대비 배치
│문제점│           빨강 │ 초록             │
├──────┼─────────────────────────────────┤
│ 기대 │ ✓지표 ✓지표 ✓지표 ✓지표 ✓지표    │  라벨 + 지표 그리드
│ 효과 │                          초록     │  숫자 크게 강조
└──────┴─────────────────────────────────┘
```

### 색이 의미를 갖는다

| 색 | 의미 |
|---|---|
| 다크 네이비 | 제목 · 사업 목표 |
| 빨강 | 문제점 |
| 파랑 | 해결 방안 · 참여기관 |
| 초록 | 기대 효과 · 공동기관 |

### 기술 설계 — 자유 텍스트를 그대로 그릴 수는 없다

레이아웃이 고정 슬롯 구조이므로, **본문을 먼저 구조화된 JSON 으로 바꿔야 한다.**

```ts
interface PosterDoc {
  title: string;
  blocks: PosterBlock[];
}

type PosterBlock =
  | { type: 'org_grid'; items: { role: '주관'|'참여'|'공동'; name: string; lines: string[] }[] }
  | { type: 'note_bar'; icon: string; text: string }
  | { type: 'labeled_text'; label: string; tone: Tone; body: string }
  | { type: 'labeled_cards'; label: string; tone: Tone; cards: { no: number; title: string; lines: string[] }[] }
  | { type: 'compare'; leftLabel: string; left: string; rightLabel: string; right: string }
  | { type: 'metrics'; label: string; items: { value: string; caption: string; note: string }[] };

type Tone = 'navy' | 'red' | 'blue' | 'green';
```

**생성 순서**

```
사업계획서 섹션 텍스트
        ↓  Claude — 구조화 (요약 + 슬롯 배치)
    PosterDoc (JSON)
        ↓  React 렌더링
      화면 표시
        ↓  html2canvas 또는 서버 렌더
     PNG / PDF 저장
```

**왜 JSON 을 거치는가**
- 블록 단위로 클릭·편집이 가능해진다 (④번 요구사항)
- 레이아웃이 깨지지 않는다 (LLM 이 HTML 을 직접 쓰면 매번 다르게 나온다)
- 재생성 시 바뀐 블록만 다시 만들면 된다

### 분량 제약이 품질을 만든다

한 장에 다 들어가야 하므로 글자 수가 강제된다.

| 슬롯 | 상한 |
|---|---|
| 카드 제목 | 20자 |
| 카드 본문 | 3줄 × 25자 |
| 지표 값 | 8자 (`≥90%`, `≤3초`) |
| 사업 목표 | 3줄 |

넘치면 잘라내는 게 아니라 **다시 요약하게 한다.** 압축이 곧 검토다.

## ④ 부분 수정

블록마다 편집 버튼을 둔다.

```
[내부 문제점] 카드 ② 클릭
   ↓
현재: "다종 데이터·다구역 통합 부재 — CCTV·게이트·방송 이벤트 분산"
   ↓
지시 입력: "구체적인 수치를 넣어줘"
   ↓
Claude 가 해당 블록만 재생성 → 즉시 반영
```

**전체를 다시 만들지 않는다.** 블록 단위 재생성이라 빠르고, 다른 부분이 흔들리지 않는다.

---

## ⑤⑥ 최신화와 재작성

③④를 반복하면 인포그래픽이 원본 사업계획서보다 정확해진다.
이때 역방향으로 반영한다.

```
⑤ "지금까지 고치신 내용을 아이디어에 반영할까요?"
     → PosterDoc → 프로젝트의 idea / answers 갱신

⑥ [사업계획서 다시 쓰기] 버튼
     → 갱신된 내용으로 7개 섹션 재생성
```

⑥을 자동으로 돌리지 않는 이유: 사용자가 원치 않는 시점에 본문이 바뀌면 안 된다.

## 경쟁사·유사 사업 조사

> "젬마가 비슷한 사업 아이템 기업들 찾아올 수 있나?"

**Gemma 로는 안 됩니다.**

| | Gemma (로컬) | Claude |
|---|---|---|
| 인터넷 접근 | ❌ 없음 | ✅ 웹 검색 |
| 최신 정보 | ❌ 학습 시점 고정 | ✅ 실시간 |
| 한국 기업 정보 | ❌ 거의 모름 | ✅ 검색으로 확보 |

Gemma 4b 는 로컬 모델이라 네트워크에 나가지 않는다.
학습 데이터에 있는 지식만 말하는데, 한국 스타트업 정보는 사실상 없고
있어도 오래됐거나 지어낸다. **경쟁사 조사에 쓰면 안 된다.**

### 권장 — Claude 웹 검색

브라우저 제어까지 갈 필요 없다. 웹 검색 도구면 충분하다.

```
로컬 Claude (Agent SDK)  →  WebSearch 내장
Claude API               →  web_search 서버 도구
```

브라우저 제어는 로그인이 필요한 사이트를 볼 때만 의미가 있다.
경쟁사 조사는 공개 정보라 검색으로 해결된다.

### 역할 정리

```
Gemma   공고 자격 판정      로컬 · 무료 · 매일 196건
Claude  사업계획서 작성      품질 우선
Claude  인포그래픽 구조화    레이아웃 슬롯 배치
Claude  경쟁사 조사         웹 검색 필요
```

## 배포 관련

로컬 실행 환경을 **맥미니로 이전 예정**.
`PlanExecutor` 인터페이스로 추상화되어 있어 실행 위치가 바뀌어도
백엔드·프론트 코드는 손대지 않는다. `AGENT_BASE_URL` 만 바꾸면 된다.
