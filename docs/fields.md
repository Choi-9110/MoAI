# moai — 입력 필드 정의

> 원칙: **한 번 입력해두면 알아서 되게 한다.**
> 사용자가 같은 정보를 두 번 입력하는 화면은 만들지 않는다.

---

## 0. 정보 흐름

```
① 회원가입     최소 정보만 (이메일 + 비밀번호)
      ↓
② 기업 정보    한 번 입력 → 공고 자격 판정 + 사업계획서 작성에 계속 재사용
      ↓
③ 대시보드     입력된 정보로 자동 판정된 결과를 보여줌
      ↓
④ 사업계획서   ②에서 아는 건 안 묻고, 모르는 것만 질문
```

②를 채우면 ③④가 자동으로 채워지는 구조가 핵심이다.

---

## 1. 회원가입 (최소 3개)

가입 단계에서는 최소한만 받는다. 나머지는 대시보드에서 유도한다.

| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| `email` | email | ✅ | 로그인 ID |
| `password` | password | ✅ | 8자 이상 |
| `name` | text | ✅ | 담당자 이름 |

> 회사명·업종을 가입 단계에서 묻지 않는다. 이탈률만 올린다.
> 가입 직후 대시보드에서 "기업 정보를 입력하면 지원 가능한 공고를 찾아드려요" 로 유도한다.

---

## 2. 기업 정보 — 가장 중요한 화면

**이 7개가 공고 자격 판정의 전부다.** (`EligibilityService` 검사 항목과 1:1 대응)

| 필드 | 타입 | 필수 | 판정 용도 | 입력 힌트 |
|---|---|---|---|---|
| `name` | text | ✅ | 서류 자동 기입 | 사업자등록증상 상호 |
| `industry` | select | ⭐ | **업종 요건** | IT·제조·바이오·콘텐츠·유통·서비스·식품·건설 |
| `region` | select | ⭐ | **지역 요건** | 서울·경기·인천 … (광역 단위) |
| `foundedAt` | date | ⭐ | **업력 요건** | 사업자등록증상 개업일 |
| `employees` | number | ⭐ | **종업원 수 상한** | 대표 포함 |
| `annualRevenue` | number | ⭐ | **매출액 상한** | 최근 연도 기준, 원 단위 |
| `isCorporation` | toggle | ⭐ | **법인 전용 공고** | 법인 / 개인사업자 |
| `certifications` | multi | ⭐ | **필수 인증 요건** | 벤처기업·이노비즈·여성기업·사회적기업 … |
| `businessNumber` | text | | 서류 자동 기입 | 000-00-00000 |

⭐ = 비워두면 해당 공고가 **"조건부"** 로 표시된다 (지원 가능으로 단정하지 않음).

### 완성도 표시

입력한 항목 수를 백분율로 보여주고, 비어 있는 항목이 몇 건의 공고 판정을 막고 있는지 알려준다.

```
기업 정보 5/8 입력됨 · 공고 3건이 "확인 필요" 상태예요
→ [매출액] 만 넣으면 2건이 판정됩니다
```

| 4 | `solution_summary` | 실현 가능성 | |
| 5 | `differentiation` | 실현 가능성 | |
| 6 | `development_stage` | 실현 가능성 | |
| 7 | `market_size` | 시장 분석 | |
| 8 | `competitors` | 시장 분석 | |

## 6. 대시보드 구성

로그인 직후 첫 화면. **오늘 뭘 해야 하는지 3초 안에 파악**되어야 한다.

```
┌────────────────────────────────────────────────┐
│ 오늘 8월 20일 · 이번 달 마감 3건               │  ← 한 줄 요약
├──────────────┬──────────────┬──────────────────┤
│ 지원 가능 5  │ 마감 임박 2  │ 작성 중 1        │  ← 숫자 카드 3개
├──────────────┴──────────────┴──────────────────┤
│ [기업 정보 5/8 입력됨 — 3건이 판정 대기 중]     │  ← 미완성 시에만
├────────────────────────────────────────────────┤
│ 캘린더 미니 위젯          │ 마감 임박 공고 목록 │
│ (클릭 → 전체 화면 팝업)   │ D-3 소상공인…       │
│                           │ D-5 서울시 청년…    │
├───────────────────────────┴────────────────────┤
│ 진행 중인 사업계획서                            │
└────────────────────────────────────────────────┘
```

### 미니 캘린더 위젯

- 축소 상태: 이번 달 그리드 + 공고 있는 날에 점 표시
- 상단에 `오늘 8월 20일 · 공고 3건 · 지원 가능 3건`
- 클릭 → 모달로 전체 캘린더 확대 (`/calendar` 와 같은 컴포넌트 재사용)
