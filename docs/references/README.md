## PDF 를 MD 로 바꿔 두는 이유

**이 PC 에는 poppler 가 없어 Claude CLI 가 PDF 를 읽지 못한다.** 그래서
`pypdf` 로 글자만 뽑아 `.txt` 로 만든 뒤, CLI 에게 그것을 읽혀 지침 MD 를
만들었다. 실행기는 MD 만 읽는다.

원본을 매번 읽히지 않는 이유는 하나 더 있다 — 53쪽 슬라이드를 사람마다
다시 읽히면 돈이 들고, 읽을 때마다 조금씩 다르게 요약된다. 한 번 정리해
두면 모두가 같은 지침으로 쓴다.

공고가 3차로 바뀌면 `modoo/모두의창업-공고요약.md` 와
`packages/shared/src/track.ts` 의 `MODOO_NOTICE_DIGEST` 를 **함께** 고쳐야 한다.

## 왜 저장하는가

이미지는 모델에 직접 넘길 수 없다. 그래서 각 폴더의 `README.md` 가
이미지를 대신해 프롬프트로 들어간다. **자료를 추가하면 규칙 문서도 같이
갱신해야** 코드와 어긋나지 않는다.

원본은 Discord 공용 inbox 에도 남지만 거기엔 다른 프로젝트 파일이 섞여 있고
파일명이 타임스탬프라 찾을 수 없다. 그래서 여기로 복사해 둔다.
