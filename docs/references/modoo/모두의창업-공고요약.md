# 「모두의 창업 프로젝트」 통합 모집공고(2차) 요약

> 중소벤처기업부 공고 제2026-511호 (2026.8.20.) / 주관: 창업진흥원(일반·기술트랙), 소상공인시장진흥공단(로컬트랙)
> 신청: 모두의 창업 플랫폼 www.modoo.or.kr (회원가입·본인인증 후 온라인 도전신청서 작성·제출)

## 1. 사업의 지향점 (사업계획서 톤 결정 근거)

- **사업목적**: 참신한 아이디어 발굴·보육을 통해 혁신 인재의 성장을 지원하고, 누구나 자유롭게 도전할 수 있는 창업 환경 조성
- **핵심 컨셉**: "창의적인 아이디어를 가진 국민 누구나 도전", "실패에 대한 부담 완화"
- **운영방식**: 라운드별 프로그램(아이디어 → BM 고도화 → 사업화)을 거치며 단계적으로 선발하는 **토너먼트 방식**, 최종 단계는 **대국민 공개 오디션(IR)**
- 즉, 초기 서류는 "완성도 높은 기업"보다 **아이디어의 차별성·효과성·창의성**을 본다. 후반 라운드로 갈수록 MVP/시제품 결과물, 사업성, 발표(IR) 역량이 핵심이 된다.

|---|---|---|---|---|---|
| → 1R | 아이디어 심사 | 서면평가 | 멘토기관 구성 **책임멘토 3인** | 전원 → **8,000명** | 아이디어의 **차별성·효과성** / 멘토기관별 중점 평가지표(기관별 공개) / 기관별 T/O 반영 |

| → 3R | 지역 오디션 | **공개 IR(발표)** | 17개 지역허브기관 구성 **외부전문가 5인 이상** | 1,000 → **200명** (시·도별 선발) | **시제품 제작 결과**, 향후 사업계획 |
| → Final | 전국 오디션 | ① 전문가 IR 평가 → ② **대국민 공개 IR** | 전문가 + 대국민(현장·온라인) | 200 → TOP10 → **최종 5명** | 전문가·대국민 평가 종합 |

- **우선 선발(1R)**: '2026 모두의 아이디어 TOP100'(지식재산처 공고 제2026-4호) 진출자가 **동일 아이디어·동일인**으로 신청 시 1R 우선 선발
- **우선 선발(2R)**: 「2026년 모두의 창업 '대학리그'」 결선 진출 22개 팀의 대표자(팀장 기준)는 2R 우선 선발

## 10. 사업계획서 작성 시 반드시 반영할 제약

- **아이디어 독창성 요건**: 본인이 직접 착안한 아이디어만 제안 가능. 표절·도용·탈취 확인 시 선정 취소·자금/상금 환수. **정부·지자체 주관 타 공모전 수상 이력이 대외 공개된 아이디어** 또는 **이미 상용화(서비스) 중인 아이디어**는 선정 취소 및 상금 환수 대상.
- **대필 금지**: 사업계획서를 타인이 대신 작성 시 작성자와 도전자 전원이 사기·업무방해죄로 처벌될 수 있음.
- **심사 제외 항목**: 단순한 제도개선·문제제기·진정·비판·불만 표시에 관한 사항은 심사 대상 제외. → 아이디어는 반드시 **제품/서비스 형태의 사업**으로 제시해야 함.
- **불이익 요소**: 임금체불, 세금 체납, 산업재해, 불공정행위 등 사회적 물의 사실이 밝혀지면 심사 시 불이익.
- **선정 없음 가능**: 선정 기준에 부합하는 아이디어가 없으면 지원·포상 대상을 선정하지 않을 수 있음.
- **특허 관련**: 본 공모는 지식재산처 '공모전 아이디어 보호 가이드라인'을 준수. 발표·시연 등으로 공지된 발명은 공개일로부터 **12개월(디자인 6개월) 이내 출원**하지 않으면 특허를 받을 수 없으므로 조기 출원 권장.
- **방송 활용**: 대국민 창업 오디션 형식이므로 영상 활용(초상권·편집) 사전 동의 예정. 실명·아이디어 내용이 보도자료로 소개될 수 있음.
- **상금 제세공과금**: 수상자 부담.
