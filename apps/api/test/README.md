# API 테스트

**돌고 있는 서버에 실제로 요청한다.** 앱을 모의로 띄우지 않는다.

이 서비스에서 난 문제는 대부분 서비스 클래스가 아니라 **그 바깥**에서 났다 —
인증 가드가 남의 워크스페이스를 걸러 주는지, 파일 업로드에서 한글 이름이
살아남는지, 잘못된 값이 500 이 아니라 400 으로 오는지. 앱을 모의로 띄우면
그 층이 통째로 빠져서, 정작 확인하려던 것을 안 보게 된다.

## 돌리는 법

```bash
pnpm dev                          # 서버가 떠 있어야 한다
pnpm --filter @moai/api test:e2e
```

서버가 없으면 **실패가 아니라 건너뛴다.** 서버를 안 띄웠다는 이유로 빨간
줄이 뜨면 사람이 곧 무시하게 되고, 그러면 진짜 실패도 함께 묻힌다.

## 파일

| 파일 | 지키는 것 |
|---|---|
| `security.e2e-spec.ts` | 워크스페이스 격리 — **새 경로를 만들면 여기 한 줄 늘린다** |
| `features.e2e-spec.ts` | 기능 계약 — 응답에 필드가 빠지지 않는지, 잘못된 입력이 어떻게 되는지 |

## 왜 이 두 가지인가

**격리**는 한 줄이 지워지면 전부 열린다. 로그인만 하면 주소의 워크스페이스
번호를 바꿔 남의 관심 공고·기업 정보·IR 덱을 볼 수 있던 적이 있다.

**계약**은 조용히 깨진다. 표에는 있는데 응답에 없는 필드는 타입으로도 안
잡히고, 화면은 빈칸을 보여 줄 뿐 아무도 오류를 못 본다. 실제로
`businessNumber`, `sourceApi`, `outcome` 이 같은 방식으로 빠진 적이 있다.

## 테스트 계정

`moai.test.*@example.com` 을 만들고 끝나면 지운다. 중간에 멈춰서 남았다면
Supabase 사용자 목록에서 그 접두어로 찾아 지우면 된다.
