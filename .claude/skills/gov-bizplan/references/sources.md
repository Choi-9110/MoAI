# 방법론 출처 정리 (스킬 근거)

이 스킬의 원칙·워크플로우가 어디서 왔는지의 기록. 스킬 사용 시 반드시 읽을 필요는 없고, 원칙의 배경이 궁금할 때 참조.

## 출처 1 — 프롬프트 6요소 공식
일잘러탐구생활, 「[ChatGPT] 정부지원사업 사업계획서 작성 실무: 프롬프트 이렇게 만들자」 (12분, youtube.com/watch?v=bWlXFAZSChQ)

- 6요소: ①동작(요약·분석·작성·추천) ②맥락(배경·목적 — "나를 학습시킨다") ③예제(출력 견본 제시) ④역할(작성자 역할+청자 지정) ⑤형식(개조식/표/키워드) ⑥어조(명료/친절)
- 실무는 2~3개 조합이 표준. 복합 요구는 나눠 보내지 말고 한 번에 조합해야 품질이 좋다.
- 보조 명령: "다시 해줘"(직전 결과 재학습→구체화) / "마음에 안 들어"(방향 전환) / "모르면 모른다고 답해 줘"(할루시네이션 방지) / "필요하다면 질문해 줘"(요구 명확화)
- 동작만 쓰면 AI가 제멋대로 답한다 — 맥락을 넣는 순간 내 사업에 근접, 역할로 관점이 바뀌고, 예제·형식으로 편집 시간이 사라진다.

## 출처 2 — AI 리서치팀 워크플로우
바이브랩스, 「정부 과제 사업계획서, 더 이상 혼자 쓰지 마세요 (AI 리서치팀과 3시간 만에 초안 완성하는 법)」 (36분, youtube.com/watch?v=x6xE2kOvOm0)

- 철학: AI는 문장 요약 도구가 아니라 논리를 조립하는 리서치 파트너. "본문은 언제든 금방 쓴다 — 시간은 리서치에 최대로 투자하라."
- 흐름: NTIS 공고 탐색 → 첨부 전부 다운로드·HWP→PDF 변환 → 작업공간(공고문/RFP/리서치/양식/목차별 페이지) → 공고 분석(자격 판단) → RFP 분석 → 리서치 4종(논문·특허·경쟁제품·연구동향) → 목차 추출 → 목차 순서 집필(이전 산출물 전부 멘션 = 맥락 누적) → 도식화 → 교차 검증 → 한글 이식·접수
- 실패 사례: 공고문에 RFP가 2개 첨부돼 있었는데 인간이 교통정리를 안 해서 두 과제 내용이 섞임 → "처음에 방향이 명확하지 않으면 중반 이후 AI가 엉뚱한 방향으로 간다. 인간이 리딩·교통정리를 해야 한다."
- AI 초안은 초안일 뿐 — 팩트체크·비판적 검토 단계가 반드시 필요.
- 영상의 도구 분업(퍼플렉시티 코멧=리서치, 노션 AI=집필, 제미나이 딥리서치=심층 조사, 냅킨=도식, 아틀라스=검증)은 이 스킬에서 [웹검색 도구=리서치, 본 세션=집필, 서브에이전트=병렬 리서치·적대 검증, 표/도식 명세=도식화]로 대응.

## 출처 3 — 문장·증명 방법론 (기존 정본)
정지호(벤처필드), PSSD 작성전략 53p·양식 10p + 예창패 PSST 가이드 영상 2편에서 확립한 원칙을 계승:
평가표 역설계 / 증명형 문장(정량화 4규칙: 동사 교체·M+N 수치·출처 병기·개조식) / TAM-SAM-SOM 바텀업 / 준비도=단계+증거 / 진입장벽이 차별성 점수를 좌우 / 마일스톤=동사+수치+시점 / 다짐형 문장 0점.
상세: 바탕화면 「모두의 창업」 폴더의 PSST_사업계획서_작성방법 정본 2종.
