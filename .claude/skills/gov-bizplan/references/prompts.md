# 프롬프트 15종 (확정본)

`{중괄호}`는 실행 시 채운다. `@파일`은 해당 산출물을 컨텍스트에 포함시킨다는 뜻.
모든 프롬프트 앞에 공통 프리앰블을 적용한다.

## 0. 공통 프리앰블

```
너는 20년 경력의 정부 R&D 과제 전문 컨설턴트야. 전문가처럼 생각하고 행동해줘.
공통 규칙:
- 모든 주장·수치에 근거와 출처를 붙인다(증명형). 출처를 모르면 지어내지 말고 "확인 필요"로 표기한다.
- 만약 네가 모르는 내용이면 모른다고 답하고, 필요한 정보가 있으면 나에게 질문해줘.
- 본문 서술 어미는 개조식(~함/~됨/~임/~음)으로 쓴다.
- 비교는 표, 흐름은 도식(자리 표시), 추세는 그래프(자리 표시)로 제안한다.
- 이전 단계 산출물과 모순되는 내용을 쓰지 않는다. 참조 문서를 완전하게 반영한다.
```

## 사전 단계

### P1. 공고문 분석
```
@공고문.pdf
이 공고문을 처음부터 끝까지 읽고 다음을 표로 정리해줘:
모집요강 / 공모 유형 / 지원 예산·기간 / 지원 자격 및 신청 조건 / 필요 서류 / 접수 절차·일정 / 주의사항·특이사항.
정리 후, 우리 회사 상황({회사 현황 한 줄})에서 지원 자격이 되는지, 결격 요소는 없는지 판정해줘.
공고문에 RFP가 여러 개 첨부되어 있으면 목록을 보여주고 어느 RFP를 대상으로 할지 나에게 질문해줘. 임의로 정하지 마.
```

### P2. RFP 분석
```
@RFP.pdf
우리는 이 RFP에 제안한다. RFP를 분석해서 제안에 필요한 것을 체계적으로 정리해줘:
① 과제 개요와 핵심 목표 ② 핵심 개발 내용(요구 기술·성능지표) ③ 제한 조건과 운영 전략 ④ 지원 자격(연구책임자 요건 포함) ⑤ 예산 규모·연차별 배분 ⑥ 평가 기준·배점(있으면).
마지막에 "우리가 반드시 충족을 증명해야 할 항목 TOP 5"를 뽑아줘.
```

### P3. 리서치 4종 (논문/특허/경쟁 제품/연구동향 각각 실행, 결과는 파일로 보관)
```
@RFP분석.md
RFP의 핵심 기술({핵심 기술 키워드})과 관련하여 {논문|특허|경쟁 제품|국내외 기술현황·연구동향·통계}를 조사해줘.
최근 5년 이내 자료 우선, 각 항목마다 [제목/발행처·출원인/연도/핵심 내용 2줄/우리 과제와의 관련성/출처 링크] 형식으로 정리해줘.
학술 자료는 실제 존재하는 것만, 확인 불가한 것은 "확인 필요"로 표기해줘.
```

## 목차별 (1~8)

### 1. 연구개발의 필요성
```
@RFP분석.md @리서치_논문.md @리서치_특허.md @리서치_경쟁제품.md @리서치_연구동향.md
위 문서들을 완전하게 반영하여 「1. 연구개발의 필요성」을 작성해줘.
구성: ① 국내외 현황과 문제점(사고·손실·비용을 수치로: 대상 수 × 빈도 × 손실 = 연간 규모 산식 포함)
② 이 연구개발이 필요한 이유(문제가 해결되면 무엇이 얼마나 좋아지는지 기대효과 수치)
③ 선행 연구·기존 기술과의 차별성(리서치의 논문·특허를 직접 인용해 "기존은 ~까지, 본 과제는 ~를 해결" 구도).
형식: ■ 소제목 + ①②③ 개조식 서술, 문단마다 근거 출처 병기, 트렌드 나열로 시작하지 말고 문제 정의로 시작.
```

### 2. 연구개발과제의 목표
```
@1_필요성.md @리서치_논문.md @리서치_특허.md @리서치_경쟁제품.md @리서치_연구동향.md
위 문서들을 반영하여 「2. 연구개발과제의 목표」를 작성해줘.
구성: ① 최종 목표 1문장(정량 지표 포함) ② 세부 목표 2~4개(각각 핵심 기술 요소 명시)
③ 성능 목표 KPI 표: [평가 항목 | 단위 | 세계 최고 수준 | 현재 수준 | 개발 목표치 | 가중치 | 측정·평가 방법] — RFP의 요구 성능지표를 빠짐없이 포함
④ 연차별 목표(1차년도/2차년도 …).
모든 목표는 "동사(달성·확보·완료) + 수치 + 시점" 형식. 측정할 수 없는 목표는 쓰지 마.
```

### 3. 연구개발과제의 내용, 추진체계 및 일정
```
@1_필요성.md @2_목표.md
위 문서들을 반영하여 「3. 연구개발과제의 내용, 추진체계 및 일정」을 작성해줘.
구성: ① 세부 목표별 개발 내용(입력→처리→출력 흐름이 드러나게, 세부 과업 단위로 분해)
② 추진 체계: 주관/공동/위탁 기관별 역할 분담 표 + 추진체계도(도식 자리 표시) — 수행 주체 3분류(직접/신규채용/외주)와 정합
③ 연차별 추진 일정 간트 차트 표(과업 × 분기, 각 과업에 산출물 명시)
④ 마일스톤 표: [시점 M+N | 목표 | KPI | 검증 방법].
일정은 RFP의 총 연구기간({기간}) 안에서 설계해줘.
```

### 4. 연구개발 성과의 활용 방안 및 기대효과

@1_필요성.md @2_목표.md @3_내용일정.md

지나치게 길게 쓰지 말고 핵심만: ① 성과 활용 방안(적용 대상·현장, 후속 R&D, 표준화·인증)
② 기술적 기대효과 ③ 경제·산업적 기대효과(시장 규모·원가 절감·매출을 산식과 함께)
④ 사회적 기대효과(고용·안전·환경 — 수치로).
각 기대효과는 리서치의 통계·시장 자료를 인용해 근거를 붙이고, "엄청난·획기적" 같은 형용사는 금지.
```

### 5. 연구수행 역량
```
@RFP분석.md @3_내용일정.md + {연구책임자·참여자 이력, 보유 장비·실적 목록}
위 자료로 「5. 연구수행 역량」을 작성해줘.
구성: ① 연구책임자 역량 — 경력 N년, 유사 과제 수행 N건, 논문·특허 N건처럼 기간+개수 정량 서술
② 참여 연구원 편성표: [성명 | 직급 | 담당 과업(3번과 일치) | 관련 경력·근거] — 부족한 역량은 채용·외주·자문으로 보완 계획 명시
③ 유사 연구개발 수행 실적 표(과제명/기간/발주처/결과)
④ 보유 연구 장비·시설·인프라.
RFP의 연구책임자 자격 요건을 우리가 충족함을 첫 문단에서 증명해줘. 모자라면 솔직히 알려줘.
