각 산출물은 `<과제폴더>/산출물/` 아래 이 파일명으로 저장한다.

## 참조 관계

```
P1 → 공고분석.md ──(인간 게이트: 지원 여부·RFP 확정)──▶

P3 → 리서치_논문/특허/경쟁제품/연구동향.md ──▶ 1번의 근거, 2·8번의 참조
1_필요성 → 2_목표 → 3_내용일정 → 4_활용기대 → 5_역량 → 6_연구비 → 7_안전보안 → 8_사업화
(각 항목은 앞 항목 전부 + 리서치를 참조 — 맥락 누적)
```

## 사전 산출물

### 공고분석.md
- 기능: 공고문을 한 장으로 압축해 "지원할지 말지"를 결정하게 하는 판단 자료. 여기서 인간이 교통정리(지원 여부·대상 RFP 확정)를 해야 뒤가 안 꼬임.
- 구조: 공고 개요 표(사업명/주관/접수 기간·마감/예산/연구 기간) → 지원 자격·결격 → 필요 서류 체크리스트(양식 파일명 매핑) → 평가 방식·일정 → 주의사항 → [지원 판정] 자격 충족 O/X + 선택 RFP + 근거.

### RFP분석.md
- 기능: 과제 요구사항의 원장(原帳). 이후 모든 항목이 "RFP 요구를 빠짐없이 커버했는가"를 이 파일과 대조.
- 구조: 과제 개요·최종 목표(RFP 원문 표현 유지) → 요구 기술·성능지표 표[요구 항목|요구 수준|비고](2번 KPI의 원천) → 제한 조건 → 지원 자격 → 예산·기간 → 평가 기준 → 충족 증명 필요 TOP 5.

### 리서치_논문.md
- 기능: 선행 연구 지도 — 1번 차별성 근거 + 2번 목표치의 세계 수준 벤치마크.
- 구조: [제목/저자·발행처/연도/핵심 내용 2줄/관련성/링크] ×5~10건 + 시사점 요약("기존은 ~까지, ~는 미해결 → 본 과제 차별 지점"). 최근 5년 우선, 미확인 자료는 "확인 필요".

### 리서치_특허.md
- 기능: 선행 특허 지도 — 차별성 + 침해 회피 체크. 8번 IP 전략 원천.
- 구조: [특허명/출원인/출원번호·연도/청구항 핵심/차이·회피 포인트/링크] + 침해 리스크 메모 + 신규 출원 후보.

### 리서치_경쟁제품.md
- 기능: 시장의 현재 답안지 — 2번 목표치·8번 차별화 표의 원천.
- 구조: 비교표 [제품명/기업/가격/핵심 성능·스펙/한계점] ×3~5 + 자사 개발 목표 스펙 대비 행 + 추정치 각주(비공개 정보는 추론 근거 명시).

### 리서치_연구동향.md
- 기능: 거시 근거 창고 — 1번 문제의 크기·8번 시장 규모의 출처.
- 구조: ①시장 규모·성장률(연도·금액·출처) ②정책·규제 동향 ③기술 트렌드 ④사고·손실 등 문제 통계 — 전부 [수치+(출처)] 형식.

## 본문 산출물 1~8 (최종 계획서에 이식되는 초안)

### 1_필요성.md
- 기능: 심사위원 공감대 — "이 문제가 정말 문제고 지금 풀어야 한다". 진정성+구체성 득점.
- 구조: ■국내외 현황·문제점(대상 수×빈도×손실 산식) / ■필요성(해결 시 기대효과 수치) / ■선행 연구 차별성(리서치 직접 인용). 금지: 트렌드 나열 시작, 출처 없는 과장.

### 2_목표.md
- 기능: 과제의 계약서 — KPI가 곧 평가 기준. 3번 일정·6번 예산이 전부 여기 묶임.
- 구조: 최종 목표 1문장(정량) / 세부 목표 2~4(핵심 기술 요소) / KPI 표[평가 항목|단위|세계 최고|현재|개발 목표|가중치|측정 방법](RFP 요구지표 전부) / 연차별 목표. 규칙: 동사+수치+시점, 측정 불가 목표 금지.

### 3_내용일정.md
- 기능: 실행 가능성 증명 — 목표를 과업으로 분해, 누가·언제.
- 구조: 세부 목표별 개발 내용(입력→처리→출력) / 추진체계 표+도식(주관·공동·위탁, 수행주체 3분류) / 연차별 간트(과업×분기, 산출물 명시) / 마일스톤 표[M+N|목표|KPI|검증 방법].

### 4_활용기대.md
- 기능: 성과의 쓸모 증명. 간결이 원칙.
- 구조: 활용 방안(적용 현장·후속 R&D·표준화) / 기술적·경제산업적·사회적 기대효과(각각 수치+산식).

### 5_역량.md
- 기능: "이 팀이 해낼 수 있는가" — RFP 자격 요건 충족을 첫 문단에서 증명.
- 구조: 연구책임자 역량(경력 N년·유사과제 N건·논문특허 N건) / 참여 편성표(담당 과업이 3번과 1:1 정합, 부족 역량은 채용·자문 보완) / 유사 실적 표 / 보유 장비·인프라.

### 6_연구비.md
- 기능: 돈의 신뢰 — 모든 숫자에 계산식. 3번 과업과 연결 안 되는 예산 금지.
- 구조: 비목별 표[비목|산출 근거(단가×수량×기간)|연차별|합계] / RFP 한도·비목 비율 규정 체크 / 외주는 근거(비딩 2곳 등) 표기.

### 7_안전보안.md
- 기능: 규정 준수 증빙(협약 시 제출) — 승부처 아님, 표준 문안 + 과제 특성만 구체화.
- 구조: 보안등급 분류·사유 / 데이터·성과물 보안 관리 / 연구실 안전(해당 시) / 보안 서약·교육.

### 8_사업화.md
- 기능: 연구가 돈이 되는 경로 — R&D 계획서의 Scale-up. 리서치 경쟁·동향을 시장 근거로 재사용.
- 구조: TAM-SAM-SOM(산식·출처, 바텀업 우선) / BM 수익 공식 / 경쟁 차별화·진입장벽 표 / 사업화 로드맵(M+N: 시제품→인증→양산→매출)+3~5년 매출 추정(가정 명시) / 후속 자금 사다리.

## 공통 규칙

- 어미: 개조식(~함/~됨). 리서치 파일은 표 중심 + 개조식 혼용.
- 본문 산출물 끝에 "인용한 리서치 출처 목록"을 붙인다.
- 분량 가이드: 리서치 각 ~2쪽, 본문 항목 각 1~2쪽 (4·7번은 1쪽 이내).
